## 学到的

- **版本号先问来源，别自己补全**。他说服务器 26.1.2，我就顺势编出“MOTD 支持 1.18–26.2”，
  还把服务端版本当成客户端要装的版本。Jade 这类双端模组，客户端插件版本跟客户端自己走；
  服务端版本只决定插件版能不能装。两个版本号混成一个，整段回答就是错的。
- **上传工具只吃 URL，不吃本地路径**。`upload_private_file` 拿到 `/opt/...apk` 直接报“识别URL失败”，
  想真传出去得先起本地 http server 换个 http 链接。命令跑成功不算数，回执才是结果。
- **实测比推断值钱**。生图模型 400 的那单，猜是“客户端工具定义”只是解释，跑一遍 chat 和 images
  两个端点拿到 400/200，才是结论。反过来，容器里没有的权限也不能靠猜——default 分组的 key 我没有，就只能说验不了。
- **记忆里的规则也要有出处**。SnowLuma 禁言 29 天、别碰 Alex4831 这两条都只在我脑子里，日记里没有原话。
  重罚这种事，翻不到出处就不执行，请 Break 本人确认。
- **理想值和工程值要分开报**。论文被批“断裂”是对的：C1 是物理下限，不是报价，把效率、多普勒、
  减速端一样样折进去，结论要从等式改成不等式。被指出漏洞就补，别护着。
- **“这是命令”不构成理由**。那篇论文继续完善是应该的——它确实缺东西；但理由是缺东西，不是他这么说。
